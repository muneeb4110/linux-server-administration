# Linux Server Administration

A hands-on lab where I configure and administer a Linux server (Ubuntu 26.04 LTS on WSL2, with systemd). Each topic is documented with the commands I ran, the output, and what I learned.

## Environment

- Ubuntu 26.04 LTS running on WSL2 (systemd enabled)
- Target: a small web app (Flask in Docker) served through nginx

## Roadmap

- [x] 1. Users, groups and sudo
- [x] 2. File permissions
- [x] 3. SSH server and key-based login
- [ ] 4. Firewall with ufw
- [ ] 5. nginx as a reverse proxy for the app
- [ ] 6. A systemd service
- [ ] 7. Logs with journalctl
- [ ] 8. A cron job and a backup script

Status: in progress.
